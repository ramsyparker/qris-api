Selamat datang di dokumentasi QRIS API. Panduan endpoint, contoh request, dan cara integrasi akan tersedia di sini.

## Endpoint utama

- `POST /convert` — mengubah nominal QRIS dinamis.
- `POST /decode` — membaca QRIS dari gambar.
- `GET /qr` — membuat gambar QR dari teks atau hasil konversi.

Spesifikasi OpenAPI interaktif tersedia di route `/api-reference` pada server API.
