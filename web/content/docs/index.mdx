# QRIS API

QRIS API mengubah nominal pada payload QRIS, membaca kode QR dari gambar, dan membuat gambar QR. SDK JavaScript/TypeScript `@aaramsyy/qris-api` menyediakan metode untuk ketiga operasi tersebut.

```ts
import { QrisApi } from '@aaramsyy/qris-api';

const qris = new QrisApi();
const result = await qris.convert({
  qris: '<QRIS_VALID>',
  nominal: '10000',
});

console.log(result.qris);
console.log(result.merchantName);
```

<Callout type="info">
SDK menggunakan `https://api-qris.fixorastudio.com` secara default. Untuk server sendiri, atur opsi [`baseUrl`](/docs/configuration).
</Callout>

| Kebutuhan | Mulai dari |

## Fitur

- **Konversi** — memperbarui nominal transaksi dan CRC16 pada payload QRIS.
- **Baca gambar** — mengambil teks kode QR dari file gambar.
- **Buat gambar** — menghasilkan PNG sebagai `Blob`.
- **Tipe TypeScript** — menyediakan tipe untuk input dan hasil SDK.

## Selanjutnya

Pasang SDK melalui [panduan instalasi](/docs/installation), lalu ikuti [mulai cepat](/docs/quickstart) untuk mengirim permintaan pertama. Ganti `<QRIS_VALID>` dalam contoh dengan payload QRIS milikmu yang valid.
